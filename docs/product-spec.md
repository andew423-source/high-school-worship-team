# 찬양팀 운영 사이트 제품 요구사항

## 사용자

- 관리자: DB·학기·조·출결·등단 설정과 전체 결과 관리
- 조 담당 스탭: 담당 조 학생의 토요모임 출결 관리
- 일반 스탭: 주일 참석 여부 확인 및 배정 결과 조회

## 사용자별 진입 화면

- 관리자는 학기 선택 화면에서 인원 DB, 조 편성, 일정, 출결과 등단 관리 기능을 모두 사용한다.
- 조 담당 스탭과 일반 스탭은 학기 선택 대신 현재 학기의 주차 목록을 첫 화면으로 본다.
- 주차는 등록된 토요모임을 날짜순으로 1주차부터 번호를 붙여 표시한다.
- 주차 상세에는 출결, 모임 가이드, 읽기 전용 등단표를 표시한다.
- 출결 입력 권한은 관리자와 해당 조 담당 스탭에게만 주며 일반 스탭에게는 권한 안내를 표시한다.
- 모임 가이드는 후속 구현 전까지 준비 중 화면을 제공한다.

## 1. 조 편성

- 학기를 먼저 설정한 뒤 해당 학기의 학생 DB를 CSV/엑셀로 등록하고 직접 수정한다.
- 학생의 학년, 예배 부서, 팀, 인도자 여부와 재적 상태는 학기별로 보존한다.
- 조 개수와 학생·담당 스탭의 조별 최소·최대 인원을 각각 설정한다.
- 학생과 조 담당 스탭 모두 자동·수동 배정을 지원한다.
- 같은 조, 다른 조, 톱시드 조건은 두 명 이상의 학생을 한 조건으로 묶어 설정하며 적용 중인 조건을 목록으로 확인·삭제한다.
- 성별·학년·싱어/세션별 조별 최소 인원을 조건으로 설정할 수 있다.
- 동성조, 동학년조, 싱어·세션 분리 모드를 켜면 해당 기준을 필수 조건으로 적용하고, 끄면 가능한 한 균형 있게 섞는다.
- 자동 편성은 최소·최대 정원과 관계 조건을 먼저 지킨 뒤 여러 편성안 중 균형이 좋은 결과를 선택한다.
- 자동 편성에서는 각 조의 성별·학년·싱어/세션별 인원이 반드시 0명 또는 2명 이상이 되게 하며, 만족할 수 없으면 편성하지 않고 이유를 표시한다.
- 학생 자동 편성 시 기존 담당 스탭 배정도 비우고 조별 빈 슬롯만 제공하며 관리자가 나중에 직접 배정한다.
- 같은 조·다른 조 조건 위반 경고에는 관련 학생 이름과 현재 배정 조를 함께 표시한다.
- 조별 결과 카드는 한 줄에 배치하고 화면이 좁을 때는 다음 줄로 넘기지 않고 가로로 스크롤한다.
- 편성된 학생 명단은 조 안에서 1학년부터 학년 오름차순으로 표시한다.
- 자동 결과를 수동으로 수정한 뒤 확정할 수 있어야 하며, 이동으로 조건 위반이나 1인 구성이 생기면 사유를 보여주고 재확인한다.

## 2. 출결 관리

- 학기 시작일·종료일을 기준으로 토요일 일정을 생성한다.
- 휴강일과 임시 모임을 설정한다.
- 조 담당 스탭은 자신의 조 출결을 입력한다.
- 학생 행과 전체 모임 날짜 열로 구성된 표에서 출결을 한눈에 관리한다.
- 각 날짜 셀에서는 미입력(·), 출석, 지각, 결석만 선택한다.
- 입력한 출결은 같은 선택 목록의 미입력(·)을 골라 되돌릴 수 있다.
- 휴강일도 날짜 열에 표시하되 모든 학생 셀을 휴강으로 표시하고 입력을 막는다.
- 조 구분 행에는 담당 스탭을 표시하고 학생 순번은 조마다 1번부터 다시 시작한다.
- 표는 모바일에서 날짜 칸을 작게 유지하고 페이지 자체가 세로로 이어지도록 한다.
- 지각의 등단 자격 인정 여부는 학기 설정에서 지정한다.

## 3. 주일 등단 배정

- 등단 화면은 현재 날짜에서 가장 가까운 이번 주 주일을 기본으로 연다.
- 학생은 기본적으로 소속 부서에 배정하되, 특이사항의 직접 지정으로 다른 부서 예배에 배정할 수 있다.
- 1부와 2부의 싱어·콰이어 목표 인원을 각각 설정하며 인도자는 두 예배에 같은 1명을 공통으로 설정한다.
- 싱어·콰이어 목표 인원은 자동 배정을 위한 값으로만 사용하며, 수동 조정 후 실제 인원이 달라도 인도자 1명이 있으면 확정할 수 있다.
- 학생 후보는 해당 학기 명단의 싱어팀 중 전날 토요모임 출석자, 스탭 후보는 주일 참석이 확인된 싱어 스탭이다.
- 인도자는 학생 인도자 또는 활성 스탭 중 직접 선택하며, 미선택 시 황현민 스탭을 기본으로 한다.
- 스탭은 주일별로 참석 여부와 당일 역할(싱어·세션)을 선택하며 싱어로 선택된 스탭만 등단 후보가 된다. 이소정은 기본 세션, 다른 스탭은 기본 싱어다.
- 스탭 DB에는 성별을 저장하고 여자 싱어가 부족할 때 여자 스탭을 우선 배정한다.
- 각 부 설정 안에서 토요 출석자, 등단 대상 학생, 싱어 스탭 수를 보여준 뒤 싱어·콰이어 인원을 조정한다.
- 학생 인도자는 인도자로 배정되면 싱어·콰이어에서 제외하지만 등단 횟수에는 포함한다.
- 싱어 스탭은 싱어 또는 인도자로만 배정하며 콰이어에는 배정하지 않는다.
- 스탭은 가능하면 1·2부 중 한 번만 배정하고 인원 부족 시에만 중복 배정한다. 남는 스탭은 배정하지 않아도 된다.
- 출석한 등단 대상 학생의 70~80%를 배정하고, 남는 싱어 자리는 참석 싱어 스탭이 채운다.
- 각 부의 여자 싱어는 가능한 한 3명 이상으로 구성한다. 후보가 부족하면 부족 인원과 이유를 경고한다.
- 황현민 스탭은 인도자로는 사용할 수 있지만 자동 싱어 보완 인원에서는 제외한다.
- 지난주 미등단 후 이번 주 출석한 학생을 우선 배정하고, 다시 배정되지 않으면 이름을 경고한다.
- 학생의 3주 연속 등단을 막고, 콰이어가 있는 경우 3주 연속 싱어도 막는다.
- 특이사항은 1·2부 카드 밖의 공통 영역에 배치하며, 전체 학생 중에서 타부서 후보에 포함하는 `부서 이동`과 반드시 등단시키는 `임의 배정`을 지정한다. 임의 배정은 등단 부서와 싱어·콰이어·랜덤 역할을 선택한다.
- 자동 배정 후 이름 카드를 원하는 역할·좌우·순서 위치로 드래그해 수정한다. 수동 변경으로 3주 연속 같은 역할이나 여자 싱어 최소 인원 위반이 생기면 이름과 사유를 보여주고 재확인한다.
- 각 부 등단표 오른쪽에는 미등단 학생의 `반에서 예배하기` 명단과 참석했지만 배정되지 않은 싱어 스탭 명단을 표시한다.
- 무대와 미등단 명단 사이를 드래그해 인원을 넣고 뺄 수 있으며, 무대 이름 카드에 마우스를 올리면 제거 버튼을 표시한다. 학생을 빼면 반에서 예배하기로, 스탭을 빼면 미등단 스탭 명단으로 이동한다.

## 4. 등단표

- 인도자를 중앙에 배치한다.
- 싱어는 앞 한 줄, 콰이어는 뒤 한 줄로 좌우 균등하게 배치한다.
- 각 줄의 성비를 가능한 한 좌우 대칭으로 맞추고 여성은 중앙 쪽, 남성은 바깥쪽에 둔다.
- 1부와 2부 등단표를 별도로 생성한다.
- 홀수 인원은 경고하고, 허용할 경우 좌우 차이를 1명 이내로 유지한다.
- 화면의 무대 카드에는 이름만 표시하고 조작 안내나 스탭 표시는 노출하지 않는다.
- PNG·PDF에는 실제 등단 인원과 인도자만 담고 반에서 예배하기 및 미등단 스탭 명단은 제외한다.

## 주요 데이터

- 학생 기본 정보: 내부 ID, 이름, 비고
- 학기별 학생 명단: 학기, 학년, 성별, 예배 부서, 팀, 학생 인도자 여부, 조, 활성 상태
- 스탭: 이름, 성별, 역할, 싱어 가능 여부, 조 담당 가능 여부, 담당 조, 선호 예배, 활성 상태
- 운영 기록: 학기 일정, 출결, 주일 참석, 등단 역할, 누적·연속 등단 횟수, 수동 수정 이력

## 예외 처리

- 조 정원 또는 담당 스탭 부족
- 같은 조·다른 조 조건 충돌
- 출결 미입력 또는 등단 후보 부족
- 인도자 부재, 예배 부서 불일치, 중복 배정
- 중복 이름과 필수 DB 값 누락

이러한 경우 가능한 범위만 처리하고 부족하거나 충돌한 이유를 사용자에게 표시한다.
