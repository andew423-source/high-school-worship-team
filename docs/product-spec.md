# 찬양팀 운영 사이트 제품 요구사항

## 사용자

- 관리자: DB·학기·조·출결·등단 설정과 전체 결과 관리
- 조 담당 스탭: 담당 조 학생의 토요모임 출결 관리
- 일반 스탭: 주일 참석 여부 확인 및 배정 결과 조회

## 1. 조 편성

- 학기를 먼저 설정한 뒤 해당 학기의 학생 DB를 CSV/엑셀로 등록하고 직접 수정한다.
- 학생의 학년, 예배 부서, 팀, 인도자 여부와 재적 상태는 학기별로 보존한다.
- 조 개수와 조별 정원을 설정한다.
- 학생과 조 담당 스탭 모두 자동·수동 배정을 지원한다.
- 반드시 같은 조 또는 다른 조가 되어야 하는 관계를 설정한다.
- 자동 편성은 정원과 관계 조건을 우선하고 학년·성별·예배 부서 등의 균형을 고려한다.
- 자동 결과를 수동으로 수정한 뒤 확정할 수 있어야 한다.

## 2. 출결 관리

- 학기 시작일·종료일을 기준으로 토요일 일정을 생성한다.
- 휴강일과 임시 모임을 설정한다.
- 조 담당 스탭은 자신의 조 출결을 입력한다.
- 출결 상태는 출석, 지각, 조퇴, 결석, 사전 연락 결석, 미입력으로 관리한다.
- 지각·조퇴의 등단 자격 인정 여부는 설정할 수 있게 한다.

## 3. 주일 등단 배정

- 1부 학생은 1부, 2부 학생은 2부에만 배정한다.
- 1부와 2부의 싱어·콰이어 인원을 각각 설정하며 인도자는 각 부 1명이다.
- 학생 후보는 해당 학기 명단의 싱어팀 중 전날 토요모임 출석자, 스탭 후보는 주일 참석이 확인된 싱어 스탭이다.
- 인도자는 학생 인도자 또는 싱어 스탭 중 직접 선택한다.
- 학생 인도자는 인도자로 배정되면 싱어·콰이어에서 제외하지만 등단 횟수에는 포함한다.
- 싱어 스탭은 싱어 또는 인도자로만 배정하며 콰이어에는 배정하지 않는다.
- 스탭은 가능하면 1·2부 중 한 번만 배정하고 인원 부족 시에만 중복 배정한다. 남는 스탭은 배정하지 않아도 된다.
- 학생은 전체 등단 횟수와 싱어 횟수가 고르게 분배되도록 한다.
- 최근 연속 등단자는 후순위로 두되 후보 부족 시 예외를 허용한다.
- 자동 배정 후 역할 교체와 수동 수정을 지원하고 자격 위반이나 중복 배정은 경고한다.

## 4. 등단표

- 인도자를 중앙에 배치한다.
- 싱어는 앞줄, 콰이어는 싱어 사이의 뒤쪽에 좌우 균등하게 배치한다.
- 1부와 2부 등단표를 별도로 생성한다.
- 홀수 인원은 경고하고, 허용할 경우 좌우 차이를 1명 이내로 유지한다.
- 명단과 배치도를 이미지 또는 PDF로 공유할 수 있도록 확장 가능하게 설계한다.

## 주요 데이터

- 학생 기본 정보: 내부 ID, 이름, 비고
- 학기별 학생 명단: 학기, 학년, 성별, 예배 부서, 팀, 학생 인도자 여부, 조, 활성 상태
- 스탭: 이름, 역할, 싱어 가능 여부, 조 담당 가능 여부, 담당 조, 선호 예배, 활성 상태
- 운영 기록: 학기 일정, 출결, 주일 참석, 등단 역할, 누적·연속 등단 횟수, 수동 수정 이력

## 예외 처리

- 조 정원 또는 담당 스탭 부족
- 같은 조·다른 조 조건 충돌
- 출결 미입력 또는 등단 후보 부족
- 인도자 부재, 예배 부서 불일치, 중복 배정
- 중복 이름과 필수 DB 값 누락

이러한 경우 가능한 범위만 처리하고 부족하거나 충돌한 이유를 사용자에게 표시한다.
